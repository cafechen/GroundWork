# API and data reference / 接口与数据参考

[Documentation / 文档中心](README.md) · [Contracts / 权威字段定义](../src/contracts/platform.ts)

Engineering preview, not a stable public SDK. JSON requests; no authentication.
Never expose publicly or store secrets. POST handlers that parse bodies require
`Content-Type: application/json`. All POST requests require `Origin` exactly
matching `GROUNDWORK_ORIGIN` when set, otherwise `http://<Host>`;
platform bodies ≤4 MiB, batches ≤16 KiB, other run submissions ≤1 MiB.
Host allowlisting/origin checks are not identity checks. No real-device command API.

这是工程预览，不是稳定公共 SDK。JSON 请求，无用户认证；不能公开部署或存放秘密。
读取请求体的 POST 需 JSON Content-Type；所有 POST 的 Origin 必须与配置的 GROUNDWORK_ORIGIN 完全一致，
未配置则与 `http://<Host>` 一致；平台请求体最多
4 MiB，批次 16 KiB，其他实验提交 1 MiB。主机和来源检查不验证身份，没有真实设备命令接口。

## Current runtime / 当前运行时

Exception: run and batch cancellation handlers currently ignore the request body;
the client sends `{}`, but those handlers do not enforce JSON content-type/body
limits. Host/Origin checks still apply. This is an implementation boundary, not a
blanket body-validation guarantee. No `/api/auth/*` endpoints exist yet.
例外：单次/批次取消接口当前忽略请求体，客户端发送 `{}`，但接口不强制 JSON 类型/大小；
Host/Origin 检查仍适用，不能泛称所有接口均校验请求体。尚无登录接口。

Next.js Route Handlers own the API; Prisma persists resources and run metadata.
Errors are `{error, code, issues?}`; internal failures include an opaque requestId,
never SQL/credentials. HTTPS reverse proxies configure `GROUNDWORK_ORIGIN`.
Next.js 接口使用 Prisma 持久化；结构化错误包含可读消息、错误码及可选字段详情，
内部失败仅给 requestId，不泄露 SQL/凭证。HTTPS 代理需配置 Origin。

`POST /api/runs` queues yard/road/Chrono jobs; parks submit compiled tasks only
through their park endpoint. `GET /api/runs/:id/result` verifies the file checksum
and requires completed execution. Report/XOSC/RMF/SDF exports retain engine guards.
The old synchronous `/api/batch` is replaced by durable `/api/batches`.
独立实验排队，园区必须经园区任务接口编译；结果读取校验文件哈希及完成状态；
导出保留引擎限制。旧同步 batch 接口由持久化 `/api/batches` 替代。

| Batch API / 批次接口 | Contract / 契约 |
| --- | --- |
| `POST /api/batches` | `{config:{...yard parameters}}`; atomically queues 12 members plus immutable manifest; HTTP 202 / 原子创建12成员及不可变清单 |
| `GET /api/batches` | Latest 20 manifests, newest first / 最近20批清单，倒序 |
| `GET /api/batches/:id` | Manifest, per-pair status/evidence, deltas, summary denominators / 清单、配对证据、差值及统计分母 |
| `POST /api/batches/:id/cancel` | Cancels queued/running members only, preserves completed results / 只取消未完成成员 |

Seeds 11/42, delays 0/8/18 s, FIFO/no-exclusion policies are fixed. Incompatible
engine/version/code/input or missing/incomplete evidence is excluded from comparisons.
JSON/CSV/HTML batch exports are client-side snapshots of the displayed summary.
固定种子、延迟与配对策略；不兼容引擎/版本/代码/输入或缺失/未完成证据不参与比较。
批次 JSON/CSV/HTML 是浏览器对当前汇总的快照导出，不新增下载接口。

## Resources / 资源

`kind = maps | models | gateways | parks`. IDs are generated by the server; lists
include archived records. Responses contain record metadata (`id`, `kind`, `name`,
`version`, `archived`, timestamps) and `data`. Versions are positive integers.
列表含已归档资源，ID 由服务器生成；响应包含元数据和 `data`，版本为正整数。

| Method/path / 方法及路径 | Contract / 契约 |
| --- | --- |
| `GET /api/platform` | `{maps,models,gateways,parks}` with complete current documents including map geometry / 返回四类资源完整当前文档，含地图几何；不包含审计事件 |
| `GET /api/platform/:kind` | Full records / 完整记录列表 |
| `GET /api/platform/:kind/:id` | Latest revision; `?version=N` fetches a frozen historical revision / 最新版本，查询参数读取历史版本 |
| `GET /api/platform/:kind/:id/versions` | Revision/timestamp list / 版本及时间列表 |
| `POST /api/platform/:kind` | Create with `{name,data}`, HTTP 201 / 创建 |
| `POST /api/platform/:kind/:id` | Replace with `{name,version,data}` using current version, HTTP 200 / 携带当前版本整体更新 |
| `POST /api/platform/:kind/:id/clone` | `{name?}` creates a separate ID and version 1 / 可选名称，创建独立 ID 和版本 1 |
| `POST /api/platform/:kind/:id/archive` | `{version}`; reference guards apply / 按当前版本归档，检查引用 |
| `GET /api/platform/parks/:id/runs` | Jobs belonging to this park / 园区实验列表 |
| `POST /api/platform/parks/:id/runs` | Only `{version,taskId}`; server freezes validated inputs; HTTP 202 / 仅允许园区版本和任务 ID，由服务器生成快照 |

No PATCH/PUT/DELETE or hard-delete/restore endpoints. Update is not a merge-patch:
read latest data, edit it and submit the complete object. Saving a park replaces
its aggregate (references, objects, devices, tasks) as one revision. Never submit
a fabricated run snapshot to bypass reference/physical-device validation.

没有 PATCH/PUT/DELETE、硬删除或恢复接口。更新不是字段补丁，应先读最新数据，再
提交完整对象。园区引用、对象、设备和任务作为整体版本保存；不可伪造实验快照绕过
引用检查和实机隔离。

## Domain fields / 领域字段

| Data / 数据 | Main fields and restrictions / 主要字段与限制 |
| --- | --- |
| Map / 地图 | Schema 1, localized name, m/rad units, source/transform, 1–10 levels, vertices/lanes/walls/doors/floors/holes/models/lifts; indices and floor references validated / 名称双语、单位明确、校验顶点和楼层引用 |
| Model / 设备模型 | `category`, dimensions, `wheelbase`, `maxSpeed`, `maxSteer`, `mass`, trailer dimensions/count, sensors; wheelbase ≤ length; 0–1 trailer for tugger only / 轴距不大于车长，只有牵引车可带 0–1 挂车 |
| Gateway / 网关 | `location: local/edge/cloud`, `adapter: simulation/external`, endpoint, channel name/kind/topic; simulation must be local with no endpoint / 本地仿真不得配置外部端点 |
| Park / 园区 | `maps:[{id,version,pose}]` (1–20), `models:[{id,version}]` (1–40), `gateways:[id]` (1–20), objects ≤500, devices/tasks ≤100 each / 固定地图模型版本，含业务对象、设备和任务 |
| Device / 实例 | `id,name,kind,model,mapId,level,pose,gatewayId?,serial,channels`; kind virtual/physical; `pose:[x,y,yaw]` / 区分虚拟与真实，单位米/米/弧度 |
| Object / 业务对象 | `id,name,type,mapId,level,x,y,yaw,w,h,value,points`; route points `[x,y]` ≤500 / 路线最多 500 点，类型详见园区手册 |
| Task / 任务 | `id,name,deviceId,routeId,duration,speed,engine`; 1–180 s, 0.1–5 m/s, additionally bounded by model max speed / 还受模型速度上限约束 |

Map flags `simulation:false, liveControl:false` describe the static asset itself;
the park adapter separately consumes a limited subset (walls and route/overlays).
They do not promise a complete physics world. `chrono` may be stored as a task
engine but is rejected by the current park execution adapter. Model mass/sensors
are definitions, not effective planar physics. Quadruped/custom are not runnable.

地图的 `simulation:false, liveControl:false` 描述静态资源自身；园区适配器另行使用
墙体、路线、业务图层的有限子集，不代表完整物理世界。任务可存 `chrono`，但当前
园区执行时明确拒绝。质量和传感器只是定义，四足/自定义模型不能运行。

External endpoints accept https/wss/mqtts URLs without embedded username/password;
they are stored, not fetched. Channel names must be unique. Binding channels requires
a gateway and defined channel names. Do not include keys in URLs or descriptions.
外部端点只接受不含用户名密码的 https/wss/mqtts 地址，仅存储不连接。通道名称不能
重复，设备通道必须属于绑定网关；禁止把密钥放 URL 或描述里。

## Jobs and legacy endpoints / 实验及旧版接口

| Endpoint / 接口 | Meaning / 含义 |
| --- | --- |
| `GET /api/capabilities` | Configured engine flags/catalog/limits; `park/yard/road=true`, `chrono` reflects whether its Python env setting is nonempty, not a runtime probe / 配置能力标志；Chrono 只看环境项非空，不是实测可用性 |
| `GET /api/runs` | Retained jobs, newest first, at most 200 / 保留实验倒序，最多 200 条 |
| `POST /api/runs` | Legacy yard/road/chrono requests; park requests must use park endpoint / 旧版实验，园区需专用接口 |
| `GET /api/runs/:id` | Job state/progress/error / 状态、进度、错误 |
| `GET /api/runs/:id/result` | Computed result JSON / 结果 JSON |
| `GET /api/runs/:id/report` | HTML report / HTML 报告 |
| `POST /api/runs/:id/cancel` | Cancellation request `{}` / 请求取消 |
| `GET /api/runs/:id/rmf`, `/sdf`, `/xosc` | Legacy-only supported exports; park export rejected; Chrono XOSC rejected / 有限旧版导出，拒绝园区导出及 Chrono XOSC |
| `POST /api/plan` | `{map?}` → catalog/default structured plan / 返回目录和默认方案 |
| `POST /api/model-plan` | `{prompt,map?}` → optional configured external model gateway / 可选外部模型调用，默认关闭 |
| `POST /api/compare` | `{baseline,candidate}` job IDs; compatible engine/version/fingerprint/case required / 要求兼容的引擎、版本、指纹和案例 |

Job status `queued/running/completed/failed/cancelled/interrupted` is separate from
engine verdict. Restart retains queued jobs, which the worker continues to claim.
A running job with an expired lease becomes interrupted on the next worker tick;
an unexpired lease reserves the slot until expiry. Graceful worker shutdown marks
its active job interrupted. Interrupted jobs are not resumed/requeued automatically.
One active preview slot, 12 queued jobs, 200 stored jobs, 10-minute child timeout.
任务状态与模型判定不同；重启保留queued任务，worker继续领取。running租约过期后在
下一轮worker检查中标interrupted；未过期租约仍占槽。worker正常退出会将其活动任务
标为中断；中断任务不自动续跑或重新排队。单活动执行槽，
最多 12 排队、200 保留任务，worker 超时 10 分钟。

Typical errors: 400 validation/unsupported input, 403 host/origin, 404 missing
resource/route, 409 resource revision/reference conflict, 405 unsupported method.
Errors return `{error,code,issues?}` with readable validation details. Park-run
revision mismatch returns 409. Unsupported paths return 404; unexported HTTP
methods use the framework's 405 response. Body-parsing handlers return 413 for
oversize bodies and 415 for non-JSON content-type. Generic unexpected errors return
500 with a requestId; custom engine/Zod messages are not all fully bilingual.

典型错误：400 参数或不支持，403 主机/来源，404 缺失，409 资源版本或引用冲突，
405 方法不支持。返回可读 `{error,code,issues?}`；园区版本冲突返回 409。
未知 API 路径返回404，未导出的HTTP方法由框架返回405；读取请求体的接口超限返回413、
非 JSON 返回415，未预期异常返回500及 requestId。引擎/Zod 的部分原生错误仍非完整双语。
